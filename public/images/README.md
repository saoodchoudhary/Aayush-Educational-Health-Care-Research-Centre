# Image Upload Guide — Dr. Asif Azim Website

Upload your images to the following paths inside the `/public/images/` folder.

## Root Images

| File Name | Description |
|-----------|-------------|
| `logo.png` | Clinic or doctor logo (recommended: transparent PNG, ~200x80px) |
| `doctor.jpg` | Dr. Asif Azim portrait photo (recommended: 600x600px, face centered) |
| `hero-bg.jpg` | Hero section background (recommended: 1920x1080px, landscape) |

---

## Notes

- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`
- Images not yet uploaded will show a placeholder until the file is added
- You can add more gallery images by editing `src/pages/Gallery.jsx`
